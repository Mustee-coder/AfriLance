🌍 AfriLance

Connect. Build. Earn.

AfriLance is an AI-powered freelance marketplace designed to connect African developers with clients and companies looking for software development talent.

🚀 Features

- 👨‍💻 Developer Profiles & Portfolios
- 🧑‍💼 Client/Company Profiles
- 💼 Jobs & Applications
- 🤖 AI-Powered Job Description Generator
- 🎯 Skill-Based Developer Matching
- 📄 AI Resume/CV Builder
- 💬 Real-Time Chat
- ⭐ Reviews & Ratings
- 📑 Contracts & Milestones
- 💳 Paystack Payments
- ☁️ Cloudinary File Storage
- 🔔 Notifications
- 🛡️ Admin & Moderation
- 🔐 Authentication & Role-Based Authorization
- ⚙️ CI/CD
- 🐳 Docker

🎯 Project Goal

The goal of AfriLance is to create a modern platform where African developers can showcase their skills, find freelance opportunities, build professional resumes, communicate with clients, and get paid securely.
